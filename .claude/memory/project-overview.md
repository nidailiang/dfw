DFW 是一个股票数据分析项目，主要做 K 线图（candlestick chart）和筹码分布（chip distribution）相关的可视化。

最近的工作：
- K 线图脚本（commit `d8fdf05`）
- 筹码分布分析脚本 `chip_distribution.py`
- 使用 Python + matplotlib/mplfinance 等库做金融数据图表
