# 关键重点

大盘macd由红翻绿, 跌破黄线, 要无条件清仓

活跃市值-2.3就是空头区间

活跃市值的macd翻绿, 一定要清仓

s1级别最高

金叉空的位置滴滴 一定要走

周线级别的底背离是有参考意义的

macd的三种用法

1- 根据白线穿越0轴看空头多头区间

	macd顺周期是建仓波

2- 顶背离和底背离

3- 金叉空和死叉多

并不是每个图形都看macd

# 课堂内容

个股起来之后洗到白线位置的b1一般不可靠, 这个时候往往是macd死叉柱由红翻绿的时候, 所以一般这个位置不可靠

对于b1来讲, 不要选macd死叉 macd翻绿柱的b1, macd也不要选接近历史高位的b1

黄线位置,一般就是macd多头区间打到0轴, 这个位置不顶就是底, 如果对了,就是最低价,如果不对, 就止损出来
